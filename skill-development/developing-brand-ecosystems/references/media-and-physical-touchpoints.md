# Media and physical touchpoints

## YAGNI gate

Add a touchpoint only when it serves an audience, journey, distribution requirement, product behavior, or approved campaign. A complete ecosystem is coherent, not maximal.

## Media

For photo, video, motion, sound, illustration, or 3D, specify concept, role, formats, durations, crops, safe areas, accessibility alternatives, rights, editable sources, render pipeline, technical manifests, and QA. Use relevant media skills only after choosing the production medium.

## Physical

For packaging, print, merchandise, signage, or environment, define hierarchy, materials, color constraints, dielines, tolerances, accessibility, regulatory copy, manufacturing owner, proofing, and approval gates. Treat generic templates as working geometry; transfer to the selected manufacturer's specification before production.

## Handoff

Deliver the smallest approved master set, licenses/rights notes, production values, naming rules, and proofs. Label samples and previews so partners cannot mistake them for final assets.
