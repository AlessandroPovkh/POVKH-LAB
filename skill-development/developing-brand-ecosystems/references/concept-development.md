# Concept development

## Purpose

Translate approved strategy into a master creative direction before producing a full system.

## Method

1. Extract constraints and evaluation criteria from strategy, audience, product behavior, medium, accessibility, production, and rights.
2. Create 2–4 directions that differ in organizing idea, composition, typography, color logic, imagery, motion, and tone—not merely surface styling.
3. Show each direction on the same representative touchpoints.
4. Evaluate against the same criteria and explain trade-offs.
5. Select one master direction through approval. Record the decision and why alternatives lost.
6. Preserve rejected work as labeled process archive, never as parallel public masters.

Use `frontend-design` when a new digital visual direction must be implemented. Use `imagegen` only for raster assets; keep vector/code-native work editable in its native form.

## Completion

A concept is selected when it can generate consistent decisions across at least the core product, identity, content, and one constrained format without relying on ad-hoc decoration.
